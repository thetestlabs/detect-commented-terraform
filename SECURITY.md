# Security Policy

## Supported Versions

We support the following versions of detect-commented-terraform:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in detect-commented-terraform, please follow these steps:

1. **Do not** create a public GitHub issue
2. Email security reports to: security@thetestlabs.io
3. Include the following information:
   - A description of the vulnerability
   - Steps to reproduce the issue
   - Potential impact
   - Suggested fix (if available)

## Response Timeline

- **Initial Response**: We aim to respond within 24 hours
- **Investigation**: We will investigate and provide updates within 48 hours
- **Fix**: Critical issues will be patched within 7 days
- **Disclosure**: We will coordinate disclosure timing with you

## Scope

This security policy applies to:

- The main detect-commented-terraform package
- All official distribution channels (PyPI, GitHub releases)
- Official documentation and examples

**Out of scope:**

- Third-party integrations or forks
- Issues in dependencies (please report to respective maintainers)
- General usage questions or feature requests

## Security Best Practices

When using detect-commented-terraform:

1. Keep the tool updated to the latest version
2. Run with minimal required permissions
3. Be cautious when using the `--fix` option on production code
4. Review changes before committing fixes

## Bug Bounty

Currently, we do not have a bug bounty program, but we appreciate security researchers who responsibly disclose vulnerabilities.

Thank you for helping keep detect-commented-terraform secure!
